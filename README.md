Hay una celda que opción al que el d y dp. Se coloca 0 o N/A
Se pueden usar combinaciones como 2#4 + 1#3 para definir los aceros

Se debe determinar la funcion de area en la que varia a. f(a) = B1*a*0.35, por ejemplo para rectangular con base 0.35 m.
